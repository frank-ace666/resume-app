# 📄 简历工坊 — Resume Craft

> **轻量化简历制作桌面应用** · 面向求职新手（学生、转行从业者）
>
> Windows 10 / 11 · 完全离线 · 数据只保存在本机

## ✨ 主要功能

| 功能 | 说明 |
|------|------|
| 📝 **7 套简历模板** | 经典、现代、简约、稳重、雅致、紧凑、清新，可随时切换 |
| 🎨 **主题色** | 8 个专业预设 + 自定义，同时应用到界面和简历标题 |
| ✏️ **分区填写** | 个人信息（含头像）、教育、工作、技能、项目、自我评价 |
| 👁️ **实时预览** | A4 版式，支持缩放、适应宽度、Ctrl+滚轮、专注预览 |
| 📤 **导出 PDF** | 所见即所得，超过一页自动分页 |
| 💾 **本地保存** | 自动保存到加密文件；自动备份；也可另存为 JSON 文件或打开已有存档 |
| 🔍 **简历检查** | 检查完整性、格式、表达和一致性，给出修改建议 |

> 简历模板针对打印和机器筛选做了优化：单一强调色、技能仅列名称、不使用 emoji 图标。

## 📝 使用方法

1. 打开应用，从左侧「个人信息」开始，按分区填写简历。
2. 在编辑器顶部选择模板和主题色，右侧实时预览效果。
3. 完成后点击「导出 PDF」，选择保存位置。
4. 中途可随时保存 JSON 存档；下次打开应用会自动恢复上次内容。

## 🔒 数据与隐私

- 应用完全离线，不需要登录，也不会上传简历内容。
- 简历使用 **Windows 系统加密（DPAPI）** 保存在 `%APPDATA%\resume-app\resume-data.enc`（即 `C:\Users\<用户>\AppData\Roaming\resume-app`）；只有当前 Windows 账号能解密。
- 自动保存约 0.3 秒防抖写入加密文件；每次启动自动保留最近 5 份加密备份。可在「帮助与反馈 → 数据」里恢复最近备份、导出 JSON 或清除本机数据。
- 覆盖安装/升级不会丢失数据；旧版 localStorage 明文数据会在首次启动时自动迁移。卸载程序默认**不会**删除该目录，重装后仍可恢复。
- 换电脑或长期保存：用「保存」导出 JSON（明文，请妥善保管），在新电脑用「打开」载入；没有云端同步。加密文件绑定当前 Windows 账号，不能直接复制到另一台设备。
- 「清除本机数据」会删除加密主文件、备份和布局设置，无法撤销；也可关闭应用后删除 `%APPDATA%\resume-app`。
- 加密保护的是磁盘上的文件：其他 Windows 账号通常无法解密，但同一账号下的恶意程序仍可读取。安装包未做代码签名。
- 「简历检查」只做规则性检查与表达建议，不会编造任何经历、项目或技能。
